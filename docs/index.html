exptab — Windows 11 资源管理器窗口自动并入标签

每次 Win+E 都开出独立窗口？开启「合并标签」后，新窗口会自动变成主窗口的一个标签页，不再堆叠。

核心特性

新窗口自动并入

任务栏、Win+E、命令行打开的新窗口，出现即变成主窗口标签。

413 KB 单文件

纯 Rust + windows crate，静态链接，无 .NET 运行时依赖。

零闪屏

WinEvent hook 在窗口显示前介入，标签几乎无感出现。

低开销

空闲 CPU ≤0.6%，常驻内存约 10.7 MB；单次合并总 CPU 约 0.016 秒。

Ctrl+Shift 放行

临时不想合并？按住 Ctrl+Shift 打开窗口，或 exptab off。

CLI 控制 + 自愈

status / on / off / metrics / rescue；窗口被隐藏或移出屏幕可一键救回。

常见问题（FAQ）

exptab 解决什么问题？Windows 11 不是自带标签页吗？

Windows 11 22H2 起资源管理器有了原生标签页，但新开窗口不会自动并入已有标签：每次 Win+E 或从任务栏打开新目录，都是一个独立窗口。exptab 补这个缺口：新窗口一出现就把它并进主窗口的标签栏，同时保证原窗口不闪、不丢、不重复建标签。

和 C# 版 ExplorerTabUtility 有什么区别？

核心思路相同。exptab 是单文件 413 KB、无 .NET 运行时依赖；常驻内存约 10.7 MB（C# 版私有集约 105.6 MB）；用 WinEvent hook + COM 在窗口显示前介入，同机实测 p50 342ms vs 574ms；代码全部开源，功能范围只做核心合并（无托盘/热键/恢复标签）。

支持 Windows 10 吗？

不支持。Windows 10 的资源管理器没有标签页模型，本工具只针对 Windows 11（已在 Windows 11 26H2 / build 26300 验证）。

需要管理员权限吗？会被杀毒软件误报吗？

不需要管理员权限，普通用户权限即可运行。程序只做 Win32 窗口操作与回环 TCP 控制通道，不联网；但没有代码签名，首次运行可能触发 SmartScreen 提示（选择「更多信息 → 仍要运行」）。

会和其他标签工具冲突吗？怎么卸载？

同一时间建议只运行一个标签合并工具（如 QTTabBar、WindowTabs、C# 版 ExplorerTabUtility）。卸载：退出 exptab 后删除 exe；开过开机自启的先在设置里关闭。窗口异常被隐藏时可运行 exptab rescue 还原。

对性能有影响吗？

事件驱动等待，空闲 CPU ≤0.6%；只在窗口创建瞬间工作，合并完成后不额外占用。
